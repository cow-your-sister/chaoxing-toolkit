# 超星学习通自动化系统

超星学习通（Chaoxing）在线学习平台自动化工具，基于 [超星学习通满分助手](https://greasyfork.org/zh-CN/scripts/436994) 改造，包含用户脚本和服务端题库 API 两部分。感谢 [上游一改](https://github.com/pang-qin/chaoxing-toolkit) 提供修改框架

### 相比原版的改进

- 新增自定义题库服务器，支持对接自建 API 查询答案
- 新增 AI 解题功能，可接入任意 OpenAI 兼容服务（DeepSeek、OpenAI、通义千问等）
- 新增答题模式：**AI 直答**（不依赖题库，直接获取题目 → 请求 AI → 自动填回网页）、题库优先 + AI 兜底、仅题库
- 题目上报改为可选：默认不上报，可自行选择上报目标或填入自定义上报地址
- 保留原版全部功能：任务点自动跳转、章节测验、作业、考试、视频/音频全自动静音播放

## 使用建议

本系统提供两种答题方式，适用于不同场景：

| | AI 解题 | 题库服务器 |
|--|---------|-----------|
| **适用人群** | 个人学生 | 机构、培训中心 |
| **正确率** | 一般（依赖大模型能力） | 高（题目与答案一一对应） |
| **部署成本** | 无需部署，配置 API Key 即可 | 需要搭建服务器并导入题库 |
| **题目覆盖** | 广泛，但冷门题目可能出错 | 有限，仅限已导入的题目 |

- **个人学生**：直接使用 AI 解题即可，配置任意 OpenAI 兼容服务的 API 地址与密钥后脚本会自动调用大模型生成答案，无需额外部署。
- **机构/批量场景**：如果对正确率有严格要求（如批量刷题、机构统一管理），建议搭建题库服务器，将标准答案导入数据库，确保每道题都能精确匹配。

## 项目结构

```
├── 学习通脚本.js              # Tampermonkey 用户脚本（自动答题、视频播放、任务点导航）
├── tiku/                      # 题库服务器
│   ├── main.py                # 服务入口
│   ├── app/                   # FastAPI 应用（路由、数据库、中间件）
│   │   ├── config.py          # 配置常量
│   │   ├── database.py        # SQLite 异步数据库
│   │   ├── matching.py        # 题目匹配逻辑
│   │   ├── middleware.py       # 限流中间件
│   │   ├── schemas.py         # Pydantic 数据模型
│   │   └── routes/            # API 路由
│   ├── frontend/              # Vue 3 管理界面（Vite + Element Plus）
│   ├── templates/             # 旧版 HTML 管理界面
│   ├── tiku.json              # 题库数据
│   ├── questions.db           # SQLite 数据库
│   ├── requirements.txt       # Python 依赖
│   └── start.sh               # 启动脚本
└── .gitignore                 # Git 忽略规则
```

## 快速开始

### 1. 安装用户脚本

本脚本需要在 [Tampermonkey（篡改猴）](https://www.tampermonkey.net/) 浏览器扩展上运行，以下是详细安装教程：

**第一步：安装 Tampermonkey**

1. 打开 [Tampermonkey 官网](https://www.tampermonkey.net/)
2. 点击对应你浏览器的安装按钮（支持 Chrome、Firefox、Edge、Safari 等）
3. 在浏览器扩展商店中确认安装

**第二步：添加脚本**

1. 点击浏览器右上角的 Tampermonkey 图标
2. 选择「添加新脚本...」
3. 清空编辑器中的默认内容
4. 将 `学习通脚本.js` 的全部内容粘贴进去
5. 按 `Ctrl + S` 保存

**第三步：使用脚本**

1. 打开超星学习通网站并登录
2. 进入课程页面，脚本将自动运行
3. 点击浏览器右上角 Tampermonkey 图标可查看脚本状态和配置

### 2. 启动题库服务器

```bash
cd tiku

# 创建虚拟环境
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# 安装依赖
pip install -r requirements.txt

# 启动服务（默认端口 8001）
python main.py
```

或使用启动脚本：

```bash
./start.sh              # 默认端口 8001
./start.sh 8002         # 指定端口
./start.sh 8001 true    # 高性能模式（多工作进程）
```

启动后访问：
- 管理界面：`http://localhost:8001`
- API 接口：`http://localhost:8001/api/search`

### 3. 前端开发

```bash
cd tiku/frontend
npm install
npm run dev      # 开发模式
npm run build    # 构建到 tiku/static/
```

## API 接口

### 查询答案

```
POST /api/search
Content-Type: application/json
```

**请求参数：**

| 字段       | 类型   | 说明                     |
| ---------- | ------ | ------------------------ |
| `question` | string | 题目文本                 |
| `type`     | string | 题目类型（0-7）          |
| `key`      | string | API 密钥（可选）         |

**题目类型：**

| 值 | 类型     |
| -- | -------- |
| 0  | 单选题   |
| 1  | 多选题   |
| 2  | 填空题   |
| 3  | 判断题   |
| 4  | 简答题   |
| 5  | 名词解释 |
| 6  | 论述题   |
| 7  | 计算题   |

**响应示例：**

```json
{
  "code": -1,
  "msg": "查询成功",
  "data": {
    "answer": "A#B#C",
    "num": "1000",
    "usenum": "100"
  }
}
```

**答案格式：**
- 单选/判断题：直接返回答案文本（如 `"36V"`、`"正确"`）
- 多选题：多个答案用 `#` 分隔（如 `"A#B#C"`）
- 填空题：多个空用 `|` 分隔

## 配置说明

### 服务器环境变量

| 变量        | 默认值         | 说明                 |
| ----------- | -------------- | -------------------- |
| `PORT`      | `8001`         | 服务端口             |
| `API_KEY`   | `your_api_key` | API 认证密钥         |
| `WORKERS`   | `1`            | 工作进程数           |

### 脚本配置

在脚本配置面板中可设置：

**基础配置**
- **答题模式**：决定答案从哪里来
  - `题库优先 + AI 兜底`（默认）：先查自定义题库，查不到再交给 AI
  - `AI 直答`：跳过题库，每道题直接获取后发送给 AI，再把返回结果自动填回网页，适合没有题库的用户
  - `仅题库`：只用自定义题库，不调用 AI
- **启用自定义题库**：开启后优先使用自定义接口（`AI 直答` 模式下不会查询题库）
- **自定义题库地址**：填入 API URL（如 `http://localhost:8001/api/search`）
- **自定义题库密钥**：填入服务器要求的 API 密钥
- **启用AI自动答题**：`题库优先 + AI 兜底` 模式下题库查不到时调用 AI；`AI 直答` 模式不受此开关影响，只要填了密钥即可用
- **AI 接口地址**：**OpenAI 兼容的 chat completions 接口完整地址**，必须以 `/chat/completions` 结尾 —— 不要只填服务商主页或 `/v1`，否则会返回 404。例如：
  - DeepSeek：`https://api.deepseek.com/v1/chat/completions`
  - OpenAI：`https://api.openai.com/v1/chat/completions`
  - 其他服务商 / 自建中转：按其文档填写
- **AI 模型名称**：服务商提供的模型名，各厂商命名不同，如 `deepseek-reasoner`、`deepseek-chat`、`gpt-4o`、`qwen-plus`、`moonshot-v1-8k`
- **AI API 密钥**：服务商控制台生成的密钥
- **AI 请求超时(秒)**：默认 120 秒；推理模型（如 `deepseek-reasoner`）响应较慢，可按需调大，超时会导致该题没有答案
- **AI 无答案时重试**：默认开启；AI 请求失败、超时，或返回内容无法解析成答案时自动重试
- **AI 重试次数**：默认 2 次（范围 0-10），即没有拿到答案时最多再试几次
- **AI 重试间隔(秒)**：默认 3 秒（范围 0-60），每次重试前的等待时间

> 脚本头部已声明 `// @connect *`，因此填写任意服务商的地址都能直接请求，**不需要修改脚本头部**；油猴可能会在首次请求某个新域名时提示一次授权。

**章节配置**
- **自动答题 / 自动视频 / 自动切换 / 自动提交**：任务点自动化开关
- **最低正确率**：低于该正确率不会自动提交答案
- **视频播放倍速**：默认 16 倍（沿用原脚本行为），范围 1-16，设为 1 即原速播放
- **保持倍速**：默认开启；部分页面会把播放速度重置回 1，开启后每秒重新设置一次
- **视频播放开始**：进入视频任务点后等播放器元素（`#video_html5_api`）出现即开始静音、按设定倍速播放，不额外等待视频元数据
- **暂停接管**：脚本会接管播放器的 `pause`——页面在切换标签 / 失焦时会调用它暂停视频，这里直接屏蔽掉；同时脚本自身也不做真实的"暂停 → 播放"切换（反复暂停播放会触发风控）。只有视频播到结尾（或触发 `ended`）时才把 `pause` 还原
- **任务点完成判定**：优先使用页面的 `isUnFinishJob()`；页面没有这个函数时改用播放进度兜底（`ended` 或 `currentTime >= duration - 1`），进度未知时按"未完成"处理，避免还没播完就跳到下一个任务点
- **视频弹题自动作答**：默认开启；视频中途弹出题目时按两级策略处理：
  - **优先**读取页面在选项里标记的正确答案（`input value="true"`）并提交 —— 零延迟、不会误答，这条路径**不请求题库 / AI**
  - 若页面没有标记（结构变化等），**退而**用脚本的解题逻辑（题库 / AI，按答题模式）作答；该兜底每道题只尝试一次，避免反复请求
  - 提交做了节流：**同一道弹题最多提交 2 次**（首次 + 一次失败重试），两次之间至少间隔 3 秒；轮询期间不会重复勾选 / 重复提交，提交前还会校验题目是否已被页面切换，避免把答案提交到下一题

**题目上报**（默认关闭，不上报任何数据）
- **启用题目上报**：总开关，只有开启后做章节测验 / 作业时才会把题目与答案上报出去
- **上报目标列表**：每行两栏 —— 题库名称 + 上报地址
  - 默认预置一项 `题库海` → `http://api.tikuhai.com/save1`
  - 可点「添加目标」新增任意条目，点「删除」移除对应条目
  - 请求方式为 `POST` + JSON `{ questionList, url }`
- 上报域名同样不需要改脚本头部，由 `// @connect *` 覆盖

- 后端：Python / FastAPI / uvicorn / aiosqlite
- 前端：Vue 3 / Element Plus / Vite
- 数据库：SQLite
